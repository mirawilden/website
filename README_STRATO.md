# mirawilden.de – Websitepaket

Diese Website ist statisch und benötigt kein WordPress, keine Datenbank und keine Plugins.

## Enthalten
- index.html
- Unterseiten für Bücher, Ironwood Falls, Heimkehr, Glühende Herzen, Katzenbuckel, Kinderbücher, Über Mira, Kontakt
- Impressum und Datenschutz mit klar markierten Pflicht-Platzhaltern
- 404.html
- assets/css/style.css
- optimierte Bilder
- sitemap.xml
- robots.txt

## Veröffentlichung bei STRATO
Wenn dein STRATO Vertrag Webspace enthält:
1. Im STRATO Kundenlogin den Webspace beziehungsweise FTP Bereich öffnen.
2. Einen FTP Benutzer einrichten oder die vorhandenen Zugangsdaten verwenden.
3. Den gesamten INHALT dieses Ordners in das Web Stammverzeichnis der Domain mirawilden.de hochladen.
4. Darauf achten, dass index.html direkt im Stammverzeichnis liegt.
5. SSL für mirawilden.de aktivieren.
6. Prüfen, ob sowohl https://mirawilden.de als auch https://www.mirawilden.de funktionieren. Eine Version sollte auf die andere weiterleiten.
7. kontakt@mirawilden.de als Mailadresse einrichten, falls du sie verwenden möchtest.

Wenn dein STRATO Vertrag nur die Domain enthält, kannst du diese Dateien stattdessen kostenlos bei Cloudflare Pages hosten und die DNS Einträge der Domain entsprechend verbinden.

## Vor Livegang unbedingt erledigen
- Impressum mit den tatsächlich erforderlichen Angaben ausfüllen.
- Datenschutzerklärung an den tatsächlichen Hostinganbieter anpassen.
- Prüfen, ob kontakt@mirawilden.de existiert.
- Exakte Amazon und Goodreads Links einsetzen, sobald du sie griffbereit hast.
- Katzenbuckel und Kinderbuchcover ergänzen, sobald die finalen Dateien vorliegen.

## SEO nach Livegang
1. Google Search Console für mirawilden.de einrichten.
2. sitemap.xml einreichen.
3. mirawilden.de bei Amazon Author Central, LovelyBooks, Goodreads, Instagram, Facebook und Pinterest als Website eintragen.
4. Die Startseite und wichtige Buchseiten in Search Console zur Indexierung anstoßen.
